# Snake Game 🐍

## Description

Ce projet est un jeu Snake développé en Python avec la bibliothèque Pygame.
Le joueur contrôle un serpent qui doit manger la nourriture pour grandir et augmenter le score.
Le jeu se termine lorsque le serpent touche les bords ou son propre corps.

---

## Fonctionnalités

* Déplacement du serpent
* Score en temps réel
* Système de niveaux
* Pause du jeu
* Game Over
* Interface graphique avec grille

---

## Technologies utilisées

* Python 3
* Pygame
* Visual Studio Code
* Git & GitHub

---

## Installation

### 1. Cloner le projet

```bash
git clone https://github.com/ayariislem969-cmd/snake.game.git
```

### 2. Entrer dans le dossier

```bash
cd snake.game
```

### 3. Installer Pygame

```bash
pip install pygame
```

### 4. Lancer le jeu

```bash
python snake.py
```

---

## Contrôles

* ⬆️ Flèche Haut : Monter
* ⬇️ Flèche Bas : Descendre
* ⬅️ Flèche Gauche : Aller à gauche
* ➡️ Flèche Droite : Aller à droite
* P : Pause
* R : Recommencer
